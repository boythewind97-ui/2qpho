# 2Q-PHỞ — GitHub Pages

## Cấu trúc
- `index.html`
- `style.css`
- `script.js`
- `images/` — bỏ toàn bộ ảnh vào đây.

## Cách dùng
1. Upload 3 file HTML/CSS/JS vào repository.
2. Tạo folder `images` và upload ảnh vào đó.
3. Giữ nguyên tên file theo `script.js`.
4. Commit changes.
5. Bật GitHub Pages ở Settings → Pages → Deploy from branch.

Nếu chưa có ảnh, website vẫn chạy: vị trí ảnh sẽ hiện ô placeholder. Khi upload đúng tên ảnh, ảnh sẽ tự xuất hiện.
